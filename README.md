# 💰 GoDuitNow - Platform Pinjaman Online

Selamat datang ke **GoDuitNow**, platform pinjaman online terpercaya yang memudahkan anda untuk mendapatkan pinjaman dengan cepat dan selamat.

## 🎯 Fitur Utama

### 1. **Pendaftaran Mudah**
- Daftar dengan maklumat asas: Nama, Email, Nombor Telefon, MyKad
- Buat PIN untuk keselamatan login
- Proses cepat dan mudah

### 2. **Login Cepat**
- Login hanya dengan Nombor Telefon dan PIN
- Tidak perlu ingat password yang rumit
- Akses akaun anda dalam beberapa saat

### 3. **Dashboard Lengkap**
- Lihat ringkasan pinjaman anda
- Cek status permohonan
- Kelola semua pinjaman dalam satu tempat

### 4. **Permohonan Pinjaman**
- Pilih jumlah pinjaman (RM 1,000 - RM 50,000)
- Pilih tempoh bayaran (3, 6, 12, 24 bulan)
- Kalkulasi otomatis bayaran bulanan dan jumlah bayar balik
- Terangkan tujuan pinjaman

### 5. **Keamanan Data**
- Data anda disimpan dengan selamat
- Encryption untuk maklumat sensitif
- Privasi terjaga

## 🚀 Cara Bermula

### Langkah 1: Pendaftaran
1. Buka halaman Daftar
2. Isi maklumat peribadi anda
3. Buat PIN (4-6 digit)
4. Setuju dengan Terma & Syarat
5. Klik "Daftar Sekarang"

### Langkah 2: Login
1. Buka halaman Login
2. Masukkan Nombor Telefon anda
3. Masukkan PIN anda
4. Klik "Masuk"

### Langkah 3: Apply Pinjaman
1. Masuk ke Dashboard
2. Pilih "Apply Pinjaman"
3. Isi borang permohonan:
   - Jumlah pinjaman
   - Tempoh bayaran
   - Tujuan pinjaman
4. Semak kalkulasi bayaran
5. Hantar permohonan

## 📊 Kalkulasi Pinjaman

Kadar faedah tetap: **8% setahun**

**Contoh:**
- Pinjaman: RM 10,000
- Tempoh: 12 bulan
- Kadar: 8% p.a.
- Bayaran Bulanan: RM 870
- Jumlah Bayar Balik: RM 10,440

## ❓ Pertanyaan Lazim

**Q: Berapa lama untuk mendapat keputusan pinjaman?**
A: Biasanya 1-2 hari kerja selepas anda hantar permohonan.

**Q: Berapa jumlah maksimum pinjaman?**
A: Maksimum RM 50,000 bergantung kepada kelayakan anda.

**Q: Boleh saya mengubah PIN?**
A: Ya, anda boleh mengubah PIN di halaman Profil.

**Q: Adakah bayaran tersembunyi?**
A: Tidak. Semua kos ditunjukkan dalam kalkulasi pinjaman.
